## Description

*(paste as-is — emphasis comes from CAPS headers and blank lines, both of which the Store preserves)*

```text
DiffThis turns a plain git diff into a code review.

Pick any local git repository, choose two branches (or pin either side to a specific commit), and DiffThis renders a clean, syntax-highlighted diff with collapsible file sections. Then, with one click, it puts an AI reviewer to work on your changes — explaining what they do and flagging the things you actually care about.

REVIEW SMARTER, NOT HARDER
DiffThis sends your diff to the AI of your choice and surfaces real findings — bugs, logic errors, and security concerns — tagged by severity (critical, high, medium, low). Each finding is shown with matching visual intensity, so the things that matter jump out first.

JUMP STRAIGHT TO THE PROBLEM
When the AI references a file and line — like GitService.cs:42 — DiffThis makes it clickable. One click scrolls the diff straight to that line and highlights it. No more hunting through hundreds of lines to find what the review is talking about.

BRING YOUR OWN AI
DiffThis works with three providers, so you stay in control of your code and your costs:

- Claude, via the Claude Code CLI
- GitHub Copilot, with your GitHub account
- Ollama, running models entirely on your own hardware, fully offline

BUILT FOR REAL CODEBASES
- Syntax highlighting for C#, TypeScript, JavaScript, Go, Rust, YAML, Bash, SQL, Dockerfile, and many more
- Adjustable diff context depth (3, 10, 25, or 50 lines) to give the AI as much or as little surrounding code as you want
- Add, refresh, hide, or compare multiple AI results side by side
- Export the full diff to Markdown to share or archive
- Remembers your branch selections per repository
- Light and dark themes, with an optional font-ligature toggle

FAST, NATIVE, AND PRIVATE
DiffThis is a native Windows desktop app. Your repositories never leave your machine except for the diff text you explicitly send to your chosen AI provider — and with Ollama, nothing leaves at all.

Stop skimming diffs. Start reviewing them.
```
